# 真实落地项目资料索取清单

> 可脱敏客户姓名、电话和报价，但请保留文件结构、尺寸、图层和工艺信息。请尽量提供原始文件，而不是截图。

## A. 原始输入

- [ ] 现场墙面原图，未压缩版本
- [ ] 墙体宽、高及单位
- [ ] 门、柱、缺口、插座、消防设施等结构尺寸和位置
- [ ] 原始 Logo 文件及品牌规范
- [ ] 客户确认过的完整文案
- [ ] 原始宣传图片、人物图、产品图和授权素材
- [ ] 客户最初需求、参考案例或草图

## B. 设计过程

- [ ] 最终确认的效果图
- [ ] 有代表性的中间版本
- [ ] 主要修改意见或沟通记录
- [ ] 设计人员实际使用的软件及版本
- [ ] 从效果图到生产文件的操作录屏，或可接受访谈
- [ ] 设计环节的大致耗时和返工次数

## C. 最终生产资料

- [ ] 实际交给生产端的原始文件
- [ ] 所有链接图片、字体和外部资源
- [ ] 工艺、材料、厚度、颜色和安装说明
- [ ] 拆件、刀线、雕刻线、出血或安装孔信息
- [ ] 生产端反馈或退回修改记录
- [ ] 最终安装完成照片

## D. 授权与保密

- [ ] 确认资料可用于内部产品研究
- [ ] 确认哪些文件允许上传第三方 AI 服务
- [ ] 明确需要脱敏的字段
- [ ] 明确案例保存期限和可访问人员
