# 文化墙概念图 → 可编辑资产：实施状态

## 已实现的流程演示

- 中转站与百炼分成独立的服务端适配器。供应商由服务器配置选择；前端、项目和已生成图片不依赖供应商。中转站保持原默认值。
- 百炼 Qwen Image 3.0 的 JSON 文生图/参考图编辑格式已通过模拟接口测试，尚未在真实账户、地域和账单下调用。
- 当前中转站配置的模型 ID 为 `gpt-image-2.5`。这是中转站别名，未验证其对应的上游模型；OpenAI 官方文档列出的是 `gpt-image-2.5-sunburst`、`gpt-image-2.5-flare` 等具体 ID，不应混同。
- 主页新增可选的短标题策略：默认不要求模型画长段文字，填写短标题时只要求出现一次；参考图有本地缩略图。自定义像素尺寸会先在前后端校验，不能保证中转站实际接受，尚未发送付费请求验证。
- 按受邀账号隔离的项目、素材、正视图元素和候选图记录；毫米尺寸、门/缺口、准确文案、位置与大小编辑，保存和重开。
- Fabric.js 画布用于正视稿编辑，不从透视效果图自动推断尺寸和施工路径。
- SVG 保留文字与色块对象；PSD 将各元素渲染成独立图层，文字原文仍由本站项目保存；PNG 用于预览。导出名称都标为“设计中间稿”。
- 本地及杭州 ECS 的 SSH 隧道浏览器验收覆盖新建、实测尺寸、文字和图片素材、保存重开、确认、SVG/PSD/PNG 下载及文件结构。旧生图流程使用已有图片夹具验证展示、下载、历史与继续修改，未新发付费生图调用。
- 服务器仅监听回环地址；未登录页面/API/图片均返回 401，跨受邀账号的项目与图片素材返回 404。服务重启后项目和旧图片仍可读；发布新版本时原 8 张图片及额度文件摘要保持不变。

## 2026-10-05 卡米通道单次实测

- 卡米密钥仅加入 ECS 的受保护环境文件，未写入代码、Git 或前端。用户授权使用其限额密钥做一次真实调用；没有自动重试。
- 选择 `kami-banana-4k`，实际模型 ID `gemini-3-pro-image-preview`；通过 Gemini 原生 `/v1beta/models/{model}:generateContent`，请求 `imageSize=4K`、`aspectRatio=3:2`，无参考图。
- 服务器返回并保存 JPEG 图片 `9de265b3-c223-42dc-a9c8-847144080081.jpg`；实测尺寸 5056 × 3392，文件约 8.3 MB。受邀账号经网站访问返回 200，未登录访问返回 401。模型在现有网站下拉菜单中可选。
- 本次用户输入：为一家科技企业的接待区设计一面宽约3.5米、高约2.3米的文化墙视觉概念。正面横向构图，暖白底色，深蓝与少量橙色几何线条，左侧预留企业Logo区域，中部留出大标题区域，右侧设置三块简洁内容展板。表现亚克力、金属和柔和洗墙灯的真实材质与层次。不要生成任何可见文字、数字、假字或Logo，仅留空白占位；不要人物、二维码和水印。
- 服务端还附加了 `brand` 风格、正面展示、无字留白和参考图解释等固定要求，详见 `server/domain/generation.ts`。结果符合无字留白和蓝橙构图方向，但它仍只是视觉概念图，不代表尺寸、材质或工艺准确。未取得卡米后台账单，不能断言本次扣费金额或余额。

## 待用户资料和授权

1. 提供同一真实项目的实测墙体结构、原始素材、最终效果图、实际生产原文件及人工步骤。原件只读保存、脱敏并取得第三方上传授权后，才能分析“效果图 → 生产文件”的真实断层。
2. 若同意百炼小额同题评测，提供仅部署在服务端的密钥、地域/工作空间信息和明确的调用费用许可。初轮上限 12 次：三类任务 × 两组输入 × 两供应商。中转站调用同样可能计费。对比结构、障碍物、Logo、文字、修改一致性、耗时、失败率与实际账单。
3. 请设计师用 Illustrator 打开 SVG、用 Photoshop 打开 PSD，记录字体替换、图片清晰度、图层、尺寸、工艺拆件等人工修正。无法仅靠程序解析证明生产可用。

## 保留边界

不自动把透视图转准确矢量施工图；不生成原生 .ai；不宣称 PNG/JPG 转 SVG 即生产化；不自动供应商故障切换；不加入付款、完整账号体系或本地 GPU 推理。首个真正生产化 MVP 的主流程，需要真实案例分析后另行锁定。
