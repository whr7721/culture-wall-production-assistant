# 自动颜色分层与独立 SVG：本地验收记录

本轮在 `experiment/independent-vector-assets` 分支实现。沿用现有项目、图片、SVG 导出和受邀访问接口；转换在本站 Node 工作进程中使用 Sharp 调色板与 VTracer，不产生第三方 API 费用。

## 操作流程

在“正视平面稿工作台”创建或打开项目，加入一张图片素材，点击画布中的图片对象。右侧“图片分层与 SVG 提取”默认是自动颜色分层。可以拖动框选局部，选 2–8 色并生成预览；逐层勾选后加入画布。加入后每条轮廓成为独立路径，可以移动、缩放、改色，并通过“下载选中元素 SVG”单独保存。保存项目、重新打开，确认后也可以下载整稿 SVG。仍可切换到“指定单色提取”，对一个目标颜色单独处理。

SVG 导入已支持常见的路径分组、继承纯色、命名空间和二维变换；路径进入项目后按毫米定位。`<image>`、渐变、复杂透明度和不支持的效果会提示处理，不会伪装成可编辑路径。输入限制是 1 MB/120 条路径；自动分层另有图片大小、并发和每日次数限制。

## 验证结果

- `npm test`：37 个测试通过；`npm run build` 通过。
- `npm run dev` 运行时，`npm run test:vector-browser`：实际浏览器拖拽框选，三色测试图中两层前景加入画布，保存重开，分别下载两个元素 SVG 和整稿 SVG，均通过。测试使用隔离的临时项目存储，不修改用户项目。
- 逆向分析取得的五份第三方 SVG 样本均导入成功。浏览器以 128×128 渲染输入与再导出结果，平均像素误差为 0、0、0、0、0.013（0–255 范围）。恶意事件属性被拒绝。
- 现有 ACH 案例左侧面板局部，在四色设置下提取 4 个颜色层、合计 96 条可导入路径。Inkscape 成功打开并另存该组合 SVG；打开后可查询到路径。截图和 SVG 见 `output/color-layer-acceptance/`，此目录不提交 Git。

## 质量边界和下一步

真实案例视觉检查显示：大色块、大字和外轮廓基本可用；细小中文笔画有缺口与粘连。部分颜色同时出现在背景和文字中，因此“颜色层”不等于设计语义层。程序只把单一路径且占满边缘的颜色自动判断为可取消的疑似背景；多轮廓颜色层保留选择，并提示人工核对。原图里写错的字也不会被矢量化纠正。

案例测试用 1000 mm 作为导入宽度，仅证明路径可导入；这一局部的实际制作尺寸尚未测得。Illustrator 在本机未完成实际打开验证，不能把 Inkscape 通过当作 Adobe/生产端验收。设计师还需核对正确文字、真实尺寸、路径质量和最终制作工艺。下一轮如要改善细字和同色混合问题，应选一个更小的真实局部，比较矢量化参数或保留原始 Logo/文字对象，不宜直接转换整面图。
