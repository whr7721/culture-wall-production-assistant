# SVG路径实验

分支 experiment/independent-vector-assets，回退检查点 checkpoint-2026-10-11-image-workspace 不变。无需新增依赖或付费API。

复用Fabric7.4 loadSVGFromString解析路径；网站原创薄层负责限制输入、毫米换算、路径保存和导出。没有复制整套编辑器。

已实测：脚本SVG拒绝；两个纯色path导入成独立对象；保存并重开；单路径导出400mm SVG，无image嵌入。浏览器脚本 scripts/acceptance-svg-import.ts。构建通过。

范围：带viewBox、纯色fill/stroke的path，最多40路径、100KB；不支持transform、CSS、渐变、图片、文本、use、clip和filter，遇到即拒绝而非静默丢失。不保持组结构、无节点编辑。默认整体按1000mm宽缩放（墙更窄时取墙宽），不是自动识别素材真实尺寸。填充缺省按黑色，画板显示由Fabric渲染。

数据模型新增path，整体SVG及独立SVG保留路径，PNG/PSD以路径SVG渲染成位图。真实Logo、复杂描边和目标软件兼容尚待验证；描边边界可能需要修正，导出非生产文件。未实现位图自动分层或矢量化。

回退旧版前先保留含path的新项目数据：旧代码不认识path，不能直接编辑这类项目。Git标签只保护代码，不替代项目数据备份；不删除数据来回退。

依据：https://www.fabricjs.com/api/functions/loadsvgfromstring/ 、https://github.com/fabricjs/fabric.js/releases 。
