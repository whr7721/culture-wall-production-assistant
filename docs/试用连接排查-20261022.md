调研参考：
- Microsoft Start-Process文档说明ArgumentList路径和引号处理、标准错误重定向：https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/start-process?view=powershell-5.1
- Windows OpenSSH关于known_hosts路径空格的历史问题：https://github.com/PowerShell/Win32-OpenSSH/issues/1784
- 官方密钥权限说明：https://github.com/PowerShell/Win32-OpenSSH/wiki/Security-protection-of-various-files-in-win32-openssh

实施：复用系统OpenSSH，不新增依赖；启动目录设为解压目录，key/known_hosts使用相对ASCII文件名；-F NUL隔离其他SSH配置；SID设置当前密钥文件权限；明确检查服务器TCP22；标准错误写入日志，失败时汇总至connection-diagnostic.txt；确认网站返回受邀认证响应后才打开浏览器。仍固定主机公钥，不关闭校验。

验证：Windows PowerShell5.1、中文加空格解压路径、老板原专用密钥，CheckOnly模式建立隧道并收到本站401认证响应，通过后只关闭本次测试连接。没有调用付费API。缺文件时显示明确原因并生成诊断文件。
