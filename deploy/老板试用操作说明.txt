文化墙设计工具｜受邀试用操作说明
版本：2026年10月15日（Windows电脑）

一、先打开网站

1. 把管理员发来的试用压缩包完整解压到一个文件夹。
2. 双击 Start-Trial.cmd，稍等几秒，浏览器会自动打开。
3. 浏览器询问账号密码时，输入管理员单独发给你的试用账号和密码。
4. 黑色连接窗口保持开启；结束时回到这个窗口按 Enter 即可。
5. 下次使用仍然双击 Start-Trial.cmd，不要只打开收藏的网页地址。

不需要安装开发软件，也不需要管理员打开自己的电脑。网站运行在云服务器上。
地址通常是 http://127.0.0.1:18080/；端口占用时会自动换到18081—18089，以实际打开的地址为准。

二、第一次建议这样试

用一面真实墙：先生成效果图 → 修改一次 → 转二维正视候选 → 下载图片 → 进入工作台 → 裁一个简单图标转SVG → 用设计软件打开检查。
先测试一个Logo或小图标，满意后再处理复杂区域。

三、生成文化墙效果图

1. 生成任务选择“生成上墙空间效果图（包含文案）”。
2. 在需求描述中写清行业、墙面用途、风格、颜色、想放哪些内容。
   示例：为科技公司前台设计文化墙，白底蓝色，左侧Logo，中间公司简介，右侧发展历程，简洁现代。
3. “重点标题”可选填；长文案、公司全称放在“上墙文字”里，尽量提供准确原文。
4. 上传现场墙面照片、Logo、参考效果图；仅使用有权上传的客户素材。
5. 模型可先用默认的 Image 2.5。其他模型可选，费用和效果可能不同。
6. 填写墙面宽度、高度，单位是毫米；例如宽4766、高2690。
7. 检查素材授权勾选项后，点击“生成文化墙提案”，等待结果。

“先用Kimi整理需求”是可选功能：需要时展开，填写其中尺寸、确认授权，点击“整理需求与提示词”，核对后应用到上方，再点击生图。
Kimi整理不会自动生成图片，生图与需求整理分别计费。

四、继续修改效果图

在结果下点击“作为参考继续修改”，写清要改哪里、哪些内容不变，然后再生成。
示例：保留Logo与整体布局，把右侧发展历程换成三段，主色改为深蓝，不增删公司名称。
满意后点击“下载图片”。每次真正提交生成或编辑，都可能产生费用，等待时不要连续点击。

五、把效果图转成二维平面候选

1. 在满意的效果图下点击“准备转二维正视图”。
2. 确认第一张参考图是要转换的效果图，任务已改成二维正视候选。
3. 需求中说明：去除透视、光影和场景，保留原有图形、文字和相对布局。
4. 点击“生成二维正视候选”，逐项检查Logo、文字、图形是否遗漏或改变。

这是AI重绘的平面图片，仍需核对，并非自动得到逐元素可编辑SVG，也不能保证与原效果图一比一。

六、进入工作台，保存和编辑

1. 在满意的结果下点击“进入工作台”，默认新建项目并带入图片与相关资料，不会再次生图。
2. 如要加入已有项目，先在工作台顶部“上方结果带入”选择目标项目，再点击上方结果的“进入工作台”。
3. 检查项目名、墙宽、墙高；只有实际复尺完成后才勾选“尺寸已现场复尺”。
4. 平面候选通常作为整张图片放到画布；空间效果图可能只出现在概念预览条中，可从“添加图片素材”选择对应素材加入画布。
5. 点击图片或下方对象按钮选中，拖动、缩放，或在选中面板填写位置和尺寸。
6. 可添加文字、色块或上传替换素材；选中文字对象后，才能修改画布上的字。
7. 经常点击“保存项目”。下次在“选择项目”里打开即可继续。

“原始需求与文案”默认折叠，只是原文留存，修改它不会改变画布，也不会重新生图。
切换项目或关闭页面时，未保存修改会提醒；当前电脑可能保留草稿。重新选择项目可按提示恢复，跨电脑请以服务器已保存的版本为准。
旧项目可“归档”，不删除素材；勾选“显示归档”后可恢复。

七、局部图形转SVG（重点测试）

1. 先在画布中选中一张图片，找到“图片分层与 SVG 提取”。
2. 在预览图里拖动框选一个Logo、装饰造型或图标；想处理全图时点击“重置为整图”。
3. “描摹通道”选择：
   - 本地免费描摹：适合先看大致结果，不消耗高质量描摹额度。
   - 高质量描摹：按次计费，当前最多开放10次新调用。
4. 线条类图标可先选“图标：描边”；实心图案可先选“色块：填充”。
5. 其余参数首次可保留默认；有颜色或分组要求再展开“参数说明”。
6. 点击“生成高质量 SVG”，核对费用确认后提交，等待完成。
7. 点击“下载完整 SVG”，用Illustrator等软件打开检查轮廓、颜色与尺寸。
8. 需要在本站修改时，点击“加入选中图层”，可对轮廓移动、缩放、改色，再保存项目。
9. 对象过多时可能只能下载完整SVG，不能全部加入本站画布；这时先下载检查，不必重新收费生成。

高质量通道裁剪PNG上传上限8MB；免费通道上限2MB并缩至长边1536像素。
描摹得到的是图形轮廓：它会把图片里的错误也描出来，不会自动纠正错字或错误Logo。
被描成轮廓的文字不能直接改字；需要改字时见下一节。

八、识别图片中的文字

选中图片 → 找到“OCR 文字识别与重建” → 点击“识别这张图片的文字” → 逐项核对并修改错字 → 勾选要保留的文字 → 点击“加入选中文字对象”。
加入后可以改字、字号、颜色、位置；SVG导出保留文字对象。
此项使用本地免费识别，不消耗高质量描摹额度；服务器首次识别可能较慢。
原图中的旧文字不会自动擦除，叠加后可能重影，需要人工处理底图或换干净素材。

九、导出文件

完整平面稿：保存项目 → 核对实际尺寸与元素位置 → 复尺完成后勾选确认 → 点击“确认平面稿” → 下载SVG、PNG或分层PSD。
如果确认失败，先看页面提示，检查元素是否超出墙面、是否与门/缺口冲突。

文件用途：
- 下载图片：保存AI效果图或二维候选图片。
- 完整SVG：已编辑平面稿，文字、路径和图片分别保留；其中的位图仍是位图。
- 下载选中元素SVG：独立导出文字、色块或矢量路径；图片需先描摹。
- PNG：平面稿预览，目前最长边1600像素。
- PSD：分层位图，文字层也是位图，目前最多30个独立元素。

在Illustrator等软件打开后请再核对尺寸、字体、轮廓和颜色。文字依赖目标电脑安装对应字体；这些导出属于设计中间稿，制作要求仍由设计人员和生产端确认。

十、费用与失败处理

高质量描摹配置估计0.3 PTC/次，本次网站最多10次新调用，对应3 PTC预算，实际收费以平台账单为准。
这10次仅指高质量描摹，不包括AI生图或Kimi整理；它们各有独立的试用额度和费用。
网站额度不等于平台充值余额，余额不足请联系管理员。

已有结果请展开“已保存的描摹任务”，使用“恢复结果／查看状态”或下载，不会再次调用付费接口。
页面提示可“免费本地重处理”时，可以使用此按钮。
不要为了找回结果勾选“不复用旧任务，重新付费提交”。
如果失败、超时或页面断开，先查看任务记录，不要连续重新提交；失败/未知任务会保守占用本站预算，是否实际扣费需管理员核对平台账单。

十一、遇到问题和反馈

- 网站打不开：确认已完整解压、双击Start-Trial.cmd，黑色窗口还在，网络正常。
- 账号密码不对：重新复制管理员给的账号密码，检查是否多了空格。
- 余额不足或额度用完：截图发管理员，不要反复点击。
- 图片文字或图形不对：注明哪张图、哪个区域、期望改成什么，并附截图。
- 请优先反馈：是否比手工省时间、哪一步最绕、哪些SVG导入设计软件后可用、哪些仍需要修正。

试用包和账号只供本人使用，请勿公开转发。
